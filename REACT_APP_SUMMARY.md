## 🚀 **How to Use**

### Quick Start
```bash
cd /workspace/syllable-app
./start.sh
```

### Manual Start
```bash
# Terminal 1 - Backend
cd backend && python3 app.py

# Terminal 2 - Frontend
npm run dev
```

### Access the App
- **Frontend**: http://localhost:5175
- **Backend API**: http://localhost:8000
